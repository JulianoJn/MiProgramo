
# MiProgramo

Aplicativo de lista  tarefas desenvolvido em flutter, a fima de colocar os conhecimentos pratico e posteriormente uso pessoal.

##  Tecnologias utilizadas
- Flutter
- Dart

## Funcionalidades atuais
- Interface inicial
- Barra superior customizada
- Lista de tarefas


##  Em desenvolvimento
- Adicionar tarefas
- Persistência local


## Escalabilidade 
Um sistema de gamificação
